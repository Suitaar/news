# Privacy

This page is about news.suitaar.com only. For the Suitaar service itself (your account, your alerts), see the [Suitaar privacy policy](https://suitaar.com/privacy).

- **No trackers, no cookies.** This site has no analytics, no tracking pixels and no third-party embeds.
- **Hosting.** The site is hosted on GitHub Pages. GitHub logs the IP address of every visitor and stores it for security purposes ([GitHub Pages: data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection), [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)). Suitaar does not receive these logs.
- **Feeds.** Your feed reader fetches the feeds from GitHub Pages in the same way. There is no mailing list and no sign-up.
- **Questions:** [mail@suitaar.com](mailto:mail@suitaar.com).
